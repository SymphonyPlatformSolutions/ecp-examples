Blast Demo

Send a blast message to one or more room stream IDs through Embedded Mode.

Loading Symphony

1. Message

This example renders ECP in explicit mode and calls sendMessage with mode: "blast".

Separate multiple stream IDs with commas, semicolons, or new lines. 

<script
  id="symphony-ecm-sdk"
  data-onload="onSdkLoaded"
  data-mode="full"
  render="explicit"
  src="{ECP-SDK-URL}">
</script>
window.symphony.sendMessage(
  {
    text: {
      "text/markdown": "Testing non-silent blast.",
    },
  },
  {
    mode: "blast",
    silent: false,
    users: [],
    streamIds: ["{ROOM_STREAM_ID}"],
  }
);

Silent blast support is expected at the end of June; the code path is present and the button is commented out for now.
