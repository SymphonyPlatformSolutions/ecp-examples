Send blast messages with ECP

This example renders ECP in explicit mode and uses the SDK sendMessage method to send blast messages to a configured stream.

Add an ECP container and load the SDK in explicit mode: 

          
            <div class="ecp-frame symphony-ecm" id="symphony-ecm"></div>

            <script
              id="symphony-ecm-sdk"
              data-onload="onSdkLoaded"
              data-mode="full"
              render="explicit"
              src="{ECP-SDK-URL}">
            </script>

Once ECP is ready, call sendMessage with mode: "blast". The silent option controls whether the blast sends a notification. 

          
            window.symphony.sendMessage(
              {
                text: {
                  "text/markdown": "Testing non silent blast.",
                },
              },
              {
                mode: "blast",
                silent: false,
                users: [],
                streamIds: ["trJ1BEjB2OIGsZVsF3s0d3///nzEkpvDdA=="],
              }
            );
